# KR Monitor Android

Нативное Android-приложение для мониторинга клинических рекомендаций.

- Встроенный реестр: 755 КР.
- Автоматическая проверка: понедельник, 19:00 по локальному времени телефона.
- Новые и обновлённые PDF скачиваются автоматически.
- Старые существующие PDF скачиваются по нажатию, чтобы не занимать гигабайты памяти при первой установке.
- PDF: официальный сервер Минздрава `apicr.minzdrav.gov.ru`.
- Метаданные названия/ID: индексированный каталог EndoExpert с защитным порогом >=500 записей; при ошибке локальный реестр не изменяется.

## Сборка
Откройте проект в Android Studio и выберите Build > Build APK(s), либо используйте включённый GitHub Actions workflow `.github/workflows/build-apk.yml`.

Минимальная версия Android: 8.0 (API 26). Target SDK: 35.
